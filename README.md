# ⏱️ JavaScript Stopwatch

A **fully functional stopwatch** built using **HTML, CSS, and JavaScript** with a clean, intuitive interface and essential time-tracking features, designed for measuring elapsed time accurately.

---

## Features

### Basic Controls
- `Start` – begins the stopwatch.
- `Pause` – temporarily stops the timer.
- `Reset` – resets the stopwatch back to zero.

### Time Tracking
- Displays elapsed time in `HH:MM:SS` format.
- Tracks minutes and seconds accurately.
- Updates the display in real time.

### Additional Features
- `Lap` – records the current elapsed time without stopping the stopwatch.
- Displays recorded lap times.
- Allows users to track multiple time intervals.

---

## How It Works

The stopwatch uses **JavaScript timing functions** to calculate elapsed time and update the display dynamically.

**Example Usage:**
1. Press `Start` to begin timing.
2. Press `Lap` to record the current time.
3. Press `Pause` to temporarily stop the stopwatch.
4. Press `Start` again to resume.
5. Press `Reset` to clear the timer and recorded laps.

---

## Technologies Used
- **HTML** – structures the stopwatch interface.
- **CSS** – styles the layout and design.
- **JavaScript** – handles timer functionality and user interactions.
